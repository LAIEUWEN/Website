# Personal Portfolio 

## Design tokens

| Token | Hex | Tailwind |
| --- | --- | --- |
| Warm Beige | `#F5EFE6` | `bg-beige` |
| Sand / Oatmeal | `#E8DEC8` | `bg-sand` |
| Jet Black | `#111111` | `text-ink`, `border-ink` |
| Crimson Red | `#D9381E` | `bg-crimson` |
| Burnt Orange | `#E86F2C` | `bg-orange` |
| Espresso Brown | `#3E2723` | `bg-espresso` |

Hard shadows: `shadow-brutal-sm` (2px), `shadow-brutal` (4px), `shadow-brutal-lg` (6px),
`shadow-brutal-espresso`. Reusable classes: `.brutal-btn` (+ `.btn-crimson`, `.btn-beige`,
`.btn-orange`, `.btn-ink`), `.brutal-card`, `.tag`, `.input-brutal`.
